# College Decision Tracker

Search 114+ colleges to see admission rates and predicted ED/EA/RD decision release dates.

## How to run

```bash
npm install
npm run dev
```

Then open **http://localhost:5173** in your browser.

## How to build for production

```bash
npm run build
npm run preview
```

## Features
- Search any college by name
- See admission rate for each college
- Historical ED / Early Action / Regular Decision release dates (2021–2025)
- Predicted next release date based on weighted trend of past years
- 114 colleges: Ivy League, elite privates, liberal arts colleges, and top public universities
